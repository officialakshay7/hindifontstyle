Which converter do I need?

Hindi text exists in two encodings. Unicode (Mangal, Noto Sans Devanagari, anything typed on a phone) stores real Hindi letters and works everywhere. Kruti Dev is a legacy font that stores English keyboard letters and only looks like Hindi when the Kruti Dev font is selected — copy it anywhere else and you see text like fgUnh.
