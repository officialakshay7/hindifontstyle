Do Hindi fonts work for Marathi text?

Yes — Marathi uses Devanagari script, the same as Hindi. All Unicode Devanagari fonts support both languages. A font must include the specific Marathi characters (ळ, ऱ, etc.) to display correctly — all Google Fonts Devanagari fonts do.

Which font is best for Marathi?

For body text: Noto Sans Devanagari or Hind Vadodara. For display and headings: Baloo 2, Modak, or Teko. For traditional Marathi calligraphy: Amita or Tillana.
