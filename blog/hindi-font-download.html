How to Install Hindi Fonts on Every Platform

Windows

  1. Download the font ZIP from Google Fonts
  2. Extract the ZIP — you will see .ttf files
  3. Right-click any .ttf file → Install (for your user only) or Install for all users
  4. Open Word, Photoshop or any app — the font appears in the font list immediately

Mac

  1. Download and extract the ZIP
  2. Double-click the .ttf file
  3. Font Book opens — click Install Font
  4. Available immediately in all apps

Android

Android does not allow changing the system font without rooting on most devices. However, you can use downloaded Hindi fonts in apps like CapCut, Canva, and PicsArt by importing the .ttf file within those apps. In CapCut: Text → Font → My Fonts → Import.

CapCut (Most Searched)

  1. Download the .ttf file to your phone (save to Downloads folder)
  2. Open CapCut → Create project → Add clip → tap the text tool
  3. Tap Font → scroll to My Fonts at the top → tap + Import
  4. Select your downloaded .ttf file
  5. The Hindi font is now available in all your CapCut projects
